# Study Guide

Make a one-page study guide the user can review in 10 minutes.

## Steps

1. **Scope.** Ask the course, the exam, and which topics are in scope. If the user shared material, use only that material.
2. **Write the guide** with these sections, in this order:
   - **Big picture** — 3 to 5 sentences: what the topic is and why it matters.
   - **Key terms** — a table: term | one-line definition | common confusion.
   - **Core ideas** — 5 to 8 bullets, one idea each.
   - **Worked examples** — exactly 3, each with the problem, the steps, and the answer.
   - **Likely exam questions** — 5 questions, without answers.
   - **Common mistakes** — 3 bullets.
3. **Check length.** The guide must fit on one printed page. Cut detail before cutting sections.

## Rules

- Plain language. Define every symbol the first time it appears.
- Flag any fact you are not sure about.
- Offer to run the likely exam questions as a quiz afterwards.
